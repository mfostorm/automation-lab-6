# automation-lab-6

Учебный репозиторий к лабораторной работе №6 «Автоматизация процессов внедрения и поддержки компьютерных систем».

## Состав проекта

| Файл | Назначение |
|------|------------|
| `app.py` | Простое Python-приложение: расчёт стоимости заказа со скидкой |
| `test_app.py` | Автоматические тесты (pytest) |
| `requirements.txt` | Зависимости проекта |
| `.gitignore` | Правила исключения временных файлов |
| `.github/workflows/main.yml` | CI-пайплайн GitHub Actions: установка зависимостей, проверка стиля, тесты |

## Запуск

```bash
pip install -r requirements.txt
python app.py
pytest -v
```

## CI/CD

При каждом `push` и `pull request` в ветку `main` GitHub Actions автоматически устанавливает зависимости, проверяет код с помощью flake8 и запускает тесты на Python 3.11 и 3.12.
